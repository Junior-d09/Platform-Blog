# 📝 Free-Blog — La plateforme de blogs moderne

**Free-Blog** est une plateforme de blogs où l’on découvre et partage l’univers d’auteurs peu connus,  
dotés d’une **plume unique et authentique**.  
C’est un espace où chaque voix compte et chaque article raconte une histoire.

---

## 🚀 Fonctionnalités principales

- ✍️ **Publication d’articles** — crée et partage des articles facilement  
- 🔍 **Recherche intelligente** — retrouve rapidement des articles ou des auteurs  
- 💬 **Commentaires** — interagis et échange avec la communauté  
- 👤 **Bio auteur** — découvre les profils et parcours des auteurs  
- ⭐ **Favoris** — garde en mémoire tes lectures préférées  

---

## 🧠 Stack technique

- ⚡ [Next.js](https://nextjs.org) — framework React moderne  
- 💅 [TailwindCSS](https://tailwindcss.com) — design rapide et réactif  
- ☁️ Déploiement via [Netlify](https://www.netlify.com)  

---

## 💻 Installation locale

Clone le projet et installe les dépendances :

```bash
git clone https://github.com/Junior-d09/Platform-Blog
cd free-blog
npm install

Lance le serveur de développement :

npm run dev


Ensuite, ouvre ton navigateur à l’adresse :
👉 http://localhost:3000

🌍 Déploiement sur Netlify

Connecte-toi sur Netlify

Clique sur “Add new site → Import an existing project”

Sélectionne ton dépôt GitHub contenant Free-Blog

Utilise la commande de build suivante :

npm run build
et le répertoire de publication :

lua
Copier le code
.next
Clique sur Deploy et laisse Netlify faire le reste 🚀
